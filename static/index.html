Review your import

Categories are preselected from merchant rules or consistent past purchases from the same merchant. You can change them before importing. Possible duplicates start unchecked. Selecting one confirms it is a separate purchase. Invalid rows cannot be imported. Your optional category column takes priority over automatic suggestions. New categories are created only for imported expenses or refunds; income and transfers do not use spending categories. Blank category cells use automatic suggestions. Other fields are ignored.
